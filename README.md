# CopperMized

CopperMized is a lightweight Fabric modpack designed to improve Minecraft through performance optimizations and quality-of-life enhancements.

It combines carefully selected client-side mods, useful tweaks, and visual improvements to make your gameplay smoother, more comfortable, and more enjoyable without straying too far from the original Minecraft experience.

## Features

- Performance and FPS optimizations.
- Quality-of-life improvements.
- Useful client-side tweaks.
- Lightweight and carefully selected mods.
- Vanilla-inspired gameplay.

## Compatibility

- Mod loader: Fabric
- Minecraft version: 26.3
- Core mod: [Sodium](https://modrinth.com/mod/sodium)

See [INCLUDED-MODS.md](INCLUDED-MODS.md) for the full list of included mods and resource packs.

## Status

CopperMized is under active development. Release artifacts are published as `.mrpack` files through GitHub Releases and, in the future, on Modrinth.

## Repository layout

- `pack/` — source tree for the Modrinth `.mrpack` layout (`modrinth.index.json` + `overrides/`).
- `docs/` — developer and publishing documentation.
- `scripts/` — helper scripts, including `.mrpack` validation.
- `.github/` — issue templates, pull request template, and GitHub Actions.

## Getting started

1. Download the latest `.mrpack` from [GitHub Releases](../../releases).
2. Import it into a launcher that supports Modrinth modpacks (for example, Prism Launcher).
3. Launch the instance and let the launcher download the required mods.
