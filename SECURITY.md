# Security Policy

## Reporting a vulnerability

If you discover a security vulnerability in CopperMized, please do not open a public issue.

Instead, report it privately using one of the following methods:

- GitHub: use the repository's "Report a vulnerability" feature (Security tab), if available.
- Email: kusokmedi@proton.me
- Telegram: @kusokmedi52
- Signal: kusokmedi.52
- Website: https://kusokmedi.lat/

Please include:

- A description of the vulnerability.
- Steps to reproduce or proof of concept, if possible.
- The affected version or file.

## Response

You can expect an acknowledgment within a reasonable time. Fixes will be released as soon as practical, and credit will be given to the reporter unless anonymity is requested.

## Scope

This policy applies to the CopperMized repository, its documentation, and configuration files. Third-party mods included in the modpack are governed by their own security policies and licenses.
